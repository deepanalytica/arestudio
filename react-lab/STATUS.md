# Estado del laboratorio React / GSAP / Three.js / Remotion

Esta carpeta conserva una implementación modular de investigación y **no es la web publicada**. La producción principal vive en la raíz del repositorio: HTML, CSS y JavaScript progresivo, compatible con GitHub Pages sin build.

- Vite y React/TypeScript: fuente modular para futuras iteraciones.
- GSAP: animaciones de interfaz.
- Three.js: terreno procedural y visualización.
- Remotion: escenas para exportar vídeo y demos, no es necesario cargarlo en el navegador público.
- SpotlightCard: implementación propia, con patrón visual similar a React Bits; **no atribuirla al componente oficial**.
- GStack: proceso de revisión, no framework de render.

**QA requerido:** esta variante necesita `npm install`, `npm run build`, pruebas en navegador y revisión de fidelidad antes de promocionarla a producción. No incluir este laboratorio como una app operativa en mensajes comerciales.
