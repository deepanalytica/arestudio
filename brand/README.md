# AR ESTUDIO · Brand Operating System 2.0

Sitio interactivo: https://deepanalytica.github.io/arestudio/brand/

Fuente canónica: tokens.json. Generación CSS: npm run brand:tokens. Validación: npm run check.
Portafolio principal: sitio estático en ../, tematizado por site-theme.css sin alterar data.js ni el catálogo de 21 proyectos.
Recursos SVG editables: assets/mark.svg, assets/cover.svg, assets/social.svg y assets/poster.svg.
Documentos: MANUAL_DE_MARCA.md y COMUNICACION.md.
Stack: HTML/CSS/JS, GSAP como mejora progresiva, Three.js opcional solo en escritorio y con reducción de movimiento/ahorro de datos respetados.
Pruebas: checks Node + validación visual manual en 390, 768 y 1440 px, teclado, reducción de movimiento, sin WebGL.
Los SVG y pantallas son aplicaciones conceptuales, no evidencia de clientes.
