# AR Estudio — logo kit 3.0

26 variantes listas para reutilizar. Todos los SVG usan el mismo monograma AR/ con separación óptica entre A, R y slash. Los lockups ESTUDIO son trazados independientes de la fuente instalada.

## Uso

```html
<link rel="stylesheet" href="/arestudio/brand/logo-kit/ar-logo.css">
<img class="ar-logo" src="/arestudio/brand/logo-kit/svg/simbolo-tinta-transparente.svg" alt="AR Estudio">
<img class="ar-logo ar-logo--horizontal" src="/arestudio/brand/logo-kit/svg/horizontal-transparente-tinta.svg" alt="AR Estudio">
```

Catálogo completo y categorías en `manifest.json`. El slash independiente es un recurso gráfico y no reemplaza el logo. Las combinaciones están propuestas para diseño, sujetas a validación óptica y marcaria antes de registro.
